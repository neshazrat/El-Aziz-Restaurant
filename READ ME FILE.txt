*READ ME 

This is a restaurant management system for El Aziz, built using Python and Tkinter.
The system allows customers, staff and admins to log in and access different features.

*INSTRUCTIONS: 

1. Make sure Python is installed on your computer. 
2. Install required libraries such as 'TKinter' and 'sqlite3'
3. Run the program
4. The ElAziz.db database file will automatically be created once run for the first time. 
5. Follow through the program and complete necessary tasks


NOTE 1: You must create your account first, before logging in. This is all up to you.

NOTE 2: When creating your order, you must specify the quantity of the item before selecting the item, to ensure your total cost is calculated correctly. 

NOTE 3: *FOR ADMIN USERS*  The 'View Stock' and 'Vew Reports & Analytics' are unfinished features, therefore you unfortunately cannot use them. 



*Enjoy your time at El Aziz!
